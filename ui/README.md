# UI designs

Put design sources for the app's screens here — screenshots, exports, mockups, or specs.

Helpful things to include alongside each screen:

- The screen's name and where it sits in the navigation flow
- Hex colors and font names/sizes, if they aren't obvious from the image
- Which elements are interactive and what they do

These get translated into Compose composables under
`app/src/main/java/com/mustafafoisol/androidapp3/`, with shared colors and typography
going into `ui/theme/`.
